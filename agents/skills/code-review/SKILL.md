# Code review

Read the requirement and actual diff, then trace affected paths and boundaries. Prioritize correctness, authorization and data safety, performance, maintainability, accessibility where relevant, errors, test coverage and FE/BE contract compatibility. Run proportionate read-only checks when useful. Report concrete issues with file/line, trigger and consequence; separate confirmed findings from uncertainty and state untested areas. Do not change code or external state during a review unless asked.
