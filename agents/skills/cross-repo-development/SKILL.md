# Cross-repository development

Resolve repository paths from hub configuration and verify each Git root and worktree status. Inspect actual caller, controller, DTO and auth behavior. Establish or update a shared contract before dependent FE/BE changes; split tasks and allow separate branches without creating or changing branches unless requested. Implement within authorized scope, verify compatibility including errors and access control, then run relevant integration checks. Record per-repo files, tests, limitations and breaking changes in one report. Never assume a documented endpoint exists without inspecting the registered route.
