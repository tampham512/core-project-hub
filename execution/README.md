# Execution records

Tạo bản ghi từ `../templates/execution-report-template.md` trong `active/` khi bắt đầu và chuyển sang `history/` sau khi kết thúc hoặc gián đoạn. Dùng ID duy nhất, tham chiếu task và ghi kết quả có bằng chứng, blocker cùng bước tiếp theo. `templates/README.md` chỉ cách dùng template chung.

Không lưu credentials, token, URL chứa mật khẩu, dữ liệu cá nhân không cần thiết hoặc hội thoại thô. Kiểm tra lại thông tin nhạy cảm trước khi chia sẻ.
