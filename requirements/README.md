# Requirements

Tạo từ `../templates/requirement-template.md`; dùng ID duy nhất `REQ-...`, liên kết user story, acceptance criteria và task. `backlog/` chứa yêu cầu chưa lập kế hoạch, `features/` chứa yêu cầu đã phân tích; các thư mục còn lại tổ chức story và tiêu chí nghiệm thu. Không đưa secrets hoặc thông tin cá nhân vào ví dụ.
